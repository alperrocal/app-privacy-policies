# App Privacy Policies

Public policy pages only. No application source code, credentials, or player data
belongs in this repository.

## Published policies

- [Merge Kingdom](https://alperrocal.github.io/app-privacy-policies/merge-kingdom/)
- [Lexicon Atlas](https://alperrocal.github.io/app-privacy-policies/lexicon-atlas/)

Each app uses its own directory (`<app-slug>/index.html`). Add another app by
creating its directory and linking it from the root `index.html`; do not reuse
one app's statements for a different app without checking its data processing.

GitHub Pages publishes the root of `main`. Plain HTML/CSS needs no dependencies,
build step, analytics, third-party fonts, or custom domain. `.nojekyll` keeps the
site static.

The current Merge Kingdom contact is GitHub Issues. Replace it with a working
support email before public release; never publish a dummy address. Issues are
public and must not contain personal information or player records.

Changing contact details does not change the policy URL. Update the policy date
when materially changing its contents. Keep the policy in the game repository's
`docs/release/privacy-policy.md` synchronized with the published page.
Keep the Lexicon Atlas page synchronized with `PRIVACY.md` in its private app
repository. Its current support contact is also this public repository's Issues;
do not request personal data in public issues.
